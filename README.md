# Every iOS Wallpaper for Every iPhone
*These backups have not been fully tested yet, please use with caution!*

**How to use:**
- Download and extract the zip file for your appropriate iOS version.
- Navigate to Users/*Your User*/Library/Applications Support/MobileSync/Backup
- Paste the extracted folder there
- Restore your iPhone with the Finder

### Please note
*This will erase all content on your iPhone*
